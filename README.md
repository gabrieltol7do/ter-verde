# Terê Verde Online

Sistema web desenvolvido com foco em turismo sustentável, conscientização ambiental e divulgação de informações sobre parques naturais da região de Teresópolis.

---

## Sobre o Projeto

O **Terê Verde Online** é uma plataforma digital criada para facilitar o acesso a informações ambientais, trilhas ecológicas, eventos sustentáveis e status de funcionamento dos parques naturais.

O projeto busca aproximar a população da natureza através da tecnologia, promovendo:

- Turismo sustentável
- Educação ambiental
- Divulgação de eventos ecológicos
- Informações sobre trilhas e parques
- Alertas ambientais
- Navegação intuitiva entre os conteúdos

---

## Funcionalidades

### Portal Principal
- Página inicial institucional
- Sessão de parques em destaque
- Alertas ambientais
- Eventos ecológicos
- Navegação responsiva

### Página de Parques
- Cards interativos dos parques
- Navegação individual para cada parque
- Informações detalhadas
- Trilhas ecológicas
- Biodiversidade da região

### Páginas Individuais dos Parques
Cada parque possui sua própria página contendo:
- Informações ambientais
- Clima
- Trilhas
- Horário de funcionamento
- Fluxo de visitantes
- Status de funcionamento

### Área Administrativa
- Dashboard administrativo
- Alteração de status dos parques
- Modal de criação de eventos
- Indicadores do sistema
- Atividades recentes

### Login
- Tela de autenticação simulada
- Redirecionamento para dashboard administrativo
